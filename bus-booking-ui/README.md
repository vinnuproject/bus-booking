# Bus Booking UI

This is the Vue 3 web frontend for the bus booking system.

## Setup

1. Install dependencies:
   ```bash
   npm install
   ```
2. Run the app:
   ```bash
   npm run dev
   ```
3. Open the local URL shown by Vite.

## Notes

- The app uses `src/services/api.js` to send API requests to `/api`.
- Vite is configured to proxy `/api` requests to the backend running at `http://localhost:3000`.
